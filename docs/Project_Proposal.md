# Project Proposal

## Project Name
Student Grade Tracker

## Selected Organization
A small tutoring center or educational training organization.

## Business Need
Small educational organizations often track grades using paper records or several unrelated spreadsheets. This can lead to calculation mistakes, duplicate records, and difficulty finding student information. The proposed system gives staff a simple local application for maintaining student performance data.

## Proposed Solution
The Student Grade Tracker will provide a graphical Python application that allows a staff member to create student records, assign courses, enter assignment scores, review calculated averages, search records, save data, and export a CSV report.

## Planned Technologies

- Python 3
- Tkinter for the graphical interface
- JSON for persistent local storage
- CSV for report export
- Git and GitHub for version control and submission
- `unittest` for automated testing

## Success Criteria

The project will be successful when it runs without errors, contains at least three related classes, uses multiple collections, saves and reloads data, validates user input, calculates grades correctly, and provides documentation sufficient for another user to run and test the program.
