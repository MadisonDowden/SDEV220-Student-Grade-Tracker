# Sample Output

The included sample data contains two students and multiple courses. When the application opens, the dashboard displays totals for students, courses, grades, and the class average.

Example student information:

| Student | Course | Assignment | Score | Letter |
|---|---|---|---:|:---:|
| Alex Johnson | Python Programming | Variables Quiz | 92 | A |
| Alex Johnson | Python Programming | OOP Project | 88 | B |
| Alex Johnson | Database Fundamentals | SQL Lab | 95 | A |
| Jordan Lee | Web Development | HTML/CSS Project | 94 | A |
| Jordan Lee | Web Development | JavaScript Quiz | 87 | B |

The interface calculates each course average and each student's overall average automatically. A CSV export includes student, course, assignment, grade, course average, and overall average fields.
